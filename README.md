# Supplier Management System (SMS) — Live Desktop & Android App

## 1. Deploy Live Web & Laptop Desktop App (GitHub Pages / Vercel)
1. Create a new repository on GitHub (e.g., `sms-dashboard`).
2. Upload all extracted files and folders (including the hidden `.github` folder) to the repository.
3. Go to **Settings > Pages**, set Source to **Deploy from a branch** (`main` / `root`), and click **Save**.
4. Open the generated GitHub Pages URL in **Chrome or Edge** on your laptop and click the **"Install App"** button in the header to install SMS as a native Desktop App.

## 2. Download Your Android APK (Zero Android Studio Needed)
1. In your GitHub repository, open the **Actions** tab.
2. Click on **Build Android APK (SMS)** (runs automatically on every push).
3. Once the green checkmark appears (~2-3 minutes), scroll down to **Artifacts** and download **`SMS-Supplier-Management-APK`**.
4. Unzip and install `app-debug.apk` on your Android phone.
